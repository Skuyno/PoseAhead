# Как запустить PoseAhead на ноутбуке

Инструкция для Windows 10 или 11 x64 на Intel/AMD. Основной показ идёт на готовых
записях: камера, DroidCam, CUDA и NVIDIA-видеокарта для него не нужны.
Нужны Python 3.10 x64, Unity Editor 6000.3.23f1 и доступная активная лицензия Unity.
Готового переносного EXE сейчас нет. Первый запуск требует интернета для установки
зависимостей, пакетов Unity и активации; после проверки можно показывать без интернета.

## 1 Перенести проект вместе с моделями

Проще всего скопировать и полностью распаковать подготовленный архив
`PoseAhead-laptop-source-20261113.zip`, например в `C:\Projects\PoseAhead`.
Открывать программу прямо внутри ZIP нельзя.

Архив содержит исходники, Unity-проект, небольшой набор записей и четыре checkpoint.
Это не полный архив исследований и не готовая программа без установки.
В нём есть личная запись поз MeTRAbs: передавать только на свой ноутбук,
не публиковать ZIP в открытом доступе.

Если переносить папку вручную, взять `src`, `scripts`, `configs`, `requirements`,
`docs`, `tests`, `main.py`, `pyproject.toml`, `README.md`, `StartPoseAhead.cmd`.
В `unity/PoseAheadAvatar` нужны `Assets`, `Packages`, `ProjectSettings`.
Для отчёта взять `output/pdf/poseahead_advisor_report_20261020.pdf`.
Также сохранить следующие пути относительно корня проекта:

| Путь | Что в нём |
| --- | --- |
| `outputs/cmu_expanded_20260924/13_29.npz` | Запись для двух CMU сценариев |
| `outputs/cmu_expanded_20260924/13_01.npz` | Дополнительная запись, начальный выбор интерфейса |
| `outputs/fixtures/m1_raw_recording.npz` | 60 сохранённых поз MeTRAbs |
| `outputs/cmu_stability_20260927/h33_seed42/` | Модель на 33 мс |
| `outputs/cmu_stability_20260927/h66_seed42/` | Модель на 66 мс |
| `outputs/cmu_noise_training_20261003_v2/model/` | Используемая модель на 100 мс |
| `outputs/cmu_stability_20260927/h150_seed42/` | Модель на 150 мс |

В каждой папке модели нужны `model.npz`, `normalizer.json`, `manifest.json`.
Их содержимое не редактировать: контрольные суммы проверяются при загрузке.
Пути checkpoint в конфигурации уже относительные, буква диска на ноутбуке не важна.

Не копировать старую `.venv`, `.vendor`, `.git`, кэши Python и папки Unity
`Library`, `Temp`, `Logs`, `UserSettings`. Среду Python создаём заново;
Unity восстановит свой кэш. Не удалять нужные модели вместе со всей `outputs`.
В GitHub публикуются исходники, а не записи и веса из `outputs`. Поэтому одного
клонирования репозитория для всех сценариев недостаточно: нужен также демо-архив
или отдельный перенос перечисленных выше файлов.

## 2 Установить Python

Для текущей версии проекта нужен именно Python 3.10 x64. Проверенный вариант
окружения использует 3.10.11. На официальной странице выбрать
Windows installer 64 bit, при установке оставить pip, Tcl/Tk и Python Launcher.

https://www.python.org/downloads/release/python-31011/

Важное ограничение: Python 3.10 уже завершил поддержку. Здесь он используется
в отдельной среде для воспроизведения существующего проекта; это не рекомендация
выбирать его для нового проекта. Обновление стека нужно проверять отдельно,
не менять версию перед показом наугад.

Открыть PowerShell в папке распакованного проекта. Например:

```powershell
cd C:\Projects\PoseAhead
py -3.10 --version
```

Команды далее выполнять из этой папки. Если она у тебя другая, заменить только
путь в `cd`. Если команда `py` не найдена, закрыть и заново открыть PowerShell;
проверить, установлен ли Python Launcher вместе с Python.

## 3 Создать среду для показа без камеры

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements/demo-cpu.txt
.\.venv\Scripts\python.exe -m pip install --no-deps torch==2.1.0+cpu --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m pip check
```

Дождаться завершения каждой команды; при ошибке остановиться и прочитать её,
не переходить к следующему шагу. Итог `pip check`: `No broken requirements found`.
Активация `.venv` и изменение ExecutionPolicy не требуются: Python вызывается явно.
Не запускать `setup_metrabs.ps1` для этого показа, он ставит отдельный GPU-стек.
PyTorch скачивается в CPU-варианте, без CUDA и torchvision.

## 4 Проверить записи и модели

```powershell
.\.venv\Scripts\python.exe scripts/check_demo.py --load-models
```

Ожидается `"status": "ready"`, все четыре сценария доступны, у адаптивного
сценария есть `"cpu_model_smoke": "passed_60_frames"`.
Эта команда не включает камеру, не открывает Unity и не отправляет UDP.
Она проверяет файлы и выполнение модели, а не всю систему на ноутбуке.

## 5 Установить Unity и открыть проект

1. Установить Unity Hub с официального сайта: https://unity.com/download .
2. Войти в свой аккаунт и проверить доступную активную лицензию в Settings → Licenses.
   Активацию выполнить самому в Hub. Без действующей лицензии Editor не запустит проект.
3. Установить ровно Unity 6000.3.23f1. Версия есть в архиве:
   https://unity.com/releases/editor/archive . Не подменять её другой Unity 6.
   Для показа в Editor Android, iOS, WebGL и Visual Studio не нужны.
4. В Unity Hub выбрать Projects → Add → Add project from disk и указать
   `C:\Projects\PoseAhead\unity\PoseAheadAvatar`, не корень всего PoseAhead.
5. Открыть проект. Первый импорт может занять время, дождаться его завершения.
6. В Project открыть сцену
   `Assets/PoseAhead/Scenes/PoseAheadDiagnostic 1.unity`.
   Вкладка Game показывает аватар; нажать Play сверху.
7. Если Unity предлагает обновить версию проекта, отменить и проверить выбранный Editor.

Путь Unity.exe на ноутбуке будет своим, например
`C:\Program Files\Unity\Hub\Editor\6000.3.23f1\Editor\Unity.exe`.
Старый путь `F:\Unity\Editor\Unity.exe` относится к основному компьютеру.
Можно открыть Unity непосредственно через Hub и вообще не выбирать EXE в панели.

## 6 Запустить интерфейс и показать работу

В корне проекта дважды нажать `StartPoseAhead.cmd`. Если окно не открылось,
запустить из PowerShell, чтобы увидеть ошибку:

```powershell
.\.venv\Scripts\python.exe main.py gui
```

Unity должна оставаться в Play. Порт по умолчанию 5005 в панели и Unity.

1. Выбрать «1 · Проверка аватара · без камеры», нажать «Применить · без запуска»,
   затем «Запустить». За восемь секунд аватар покажет диагностические движения.
2. Проверить в панели подтверждённые счётчики Unity: «принято» и «применено».
   Счётчик отправки Python сам по себе не подтверждает получение аватаром.
3. Выбрать «2 · CMU · Калман + 100 мс», применить и запустить.
4. После окончания выбрать «3 · CMU · экспериментальная нейросеть», применить
   и запустить. Входная запись та же; вклад нейросети может отклоняться защитой.
5. При желании показать «4 · Сохранённый MeTRAbs · без камеры».
   Это 60 ранее сохранённых поз, около 2,5 секунды, не новая съёмка.
6. Открыть PDF отчёта из `output/pdf` и текст выступления
   `docs/advisor_speech_20261020.md`.

Смена сценария не запускает его автоматически. Записи не зациклены.
Свежие результаты сохраняются в отдельных `outputs/ui_...`; старые не перезаписываются.

## Если что то не работает

| Симптом | Что проверить |
| --- | --- |
| Не найдена `.venv` или `poseahead` | Выполнить шаг 3 из корня проекта |
| Не найден `torch` | Установить CPU PyTorch командой из шага 3 в эту же `.venv` |
| Не найден NPZ или checkpoint | Сверить таблицу файлов в шаге 1, восстановить структуру |
| Ошибка контрольной суммы | Копировать исходные файлы заново, не менять manifest вручную |
| Пакеты отправлены, аватар стоит | Включить Play, открыть вкладку Game, проверить порт 5005 |
| Нет подтверждения Unity | Проверить Play и свежую телеметрию; не выдавать отправку за приём |
| Ошибка лицензии Unity | Проверить аккаунт и лицензию в Hub, Python это не исправляет |
| Ошибка загрузки DLL PyTorch | Проверить Windows x64 и официальный Microsoft Visual C++ Redistributable x64; не скачивать отдельные DLL с посторонних сайтов |

Для показа на записях не нужно менять VPN, IP-адреса, firewall или настройки камер.
Запуск камеры на этом CPU-окружении не подготовлен и в этот сценарий не входит.

## Что сказать преподавателю

Показываем работающий прототип и промежуточные результаты. Наши модели прогнозируют
позу; MeTRAbs является готовым оценщиком позы и во время воспроизведения не запускается.
Ошибка и дрожание улучшились на проверенных данных, но преимущество по фактической
задержке пока не доказано. Скорость воспроизведения записи не является FPS камеры.

Полную репетицию на самом ноутбуке и активацию Unity лучше выполнить до встречи:
инструкция и тест на основном ПК не гарантируют драйверы конкретного ноутбука.
